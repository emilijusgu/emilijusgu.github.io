Ką galiu pasiūlyti

Studijų metu tobulinamos IT praktikos kryptys. Kainos pateiktos kaip mokomieji pavyzdžiai, o ne viešas komercinis pasiūlymas.

Interneto svetainių kūrimas

Struktūrizuoti HTML puslapiai, prisitaikantis CSS dizainas ir nesudėtingas JavaScript.

Duomenų vizualizavimas

MATLAB scenarijai, duomenų atvaizdavimas ir grafikų paruošimas mokymosi užduotims.

Kompiuterių tinklų pagrindai

Mokomieji tinklų planavimo, technologijų pažinimo ir dokumentavimo darbai.

Paslaugų ir įkainių lentelė

Trys praktinių IT darbų kryptys ir orientaciniai įkainiai.

Naudojamos technologijos

Šiems darbams naudoju šiuos įrankius:

  • HTML – turinio struktūrai
  • CSS – puslapio stiliams
    • Flexbox – elementų lygiavimui
    • Media queries – prisitaikymui prie įrenginių
  • JavaScript – sąveikai
  • MATLAB – skaičiavimams ir grafikams

Pirmos paslaugos atlikimo etapai

Darbo procesas nuo idėjos iki galutinio rezultato:

  1. Išsiaiškinti CV svetainės turinį ir poreikius.
  2. Sukurti puslapio struktūrą HTML kalba.
  3. Pritaikyti CSS stilius ir patikrinti veikimą.
